# LORISWMS

LORISWMS, küçük ve orta ölçekli işletmeler için geliştirilmiş basit bir **stok ve satış yönetim sistemi**dir.  
Streamlit tabanlıdır ve veriler `test.db` veritabanında saklanır.  

---

## 🚀 Nasıl Çalıştırılır?

1. Bilgisayarınıza gerekli paketleri yükleyin:
   ```
   pip install -r requirements.txt
   ```

2. Uygulamayı başlatın:
   ```
   streamlit run app.py
   ```

3. Tarayıcıda otomatik olarak açılan sayfadan uygulamayı kullanabilirsiniz.  

---

## 📂 Dosyalar
- **app.py** → Uygulama kodu  
- **requirements.txt** → Uygulamanın ihtiyaç duyduğu kütüphaneler  
- **test.db** → Verilerin saklandığı veritabanı  
- **README.md** → (bu dosya) Uygulamanın rehberi
